## Common NOC Workflow

**Monitor → Verify → Identify Impact → Perform Approved Checks → Raise/Update Ticket → Coordinate with ISP/Team → Track ETR → Verify Restoration → Monitor Stability → Document and Close**

Follow the organization's approved SOP, access rules, escalation path, and change process. Commands and checks should be performed only when authorized.

## Documentation Standards

- Use generic, sanitized scenarios instead of real production incidents.
- Record facts and timestamps accurately; distinguish confirmed causes from assumptions.
- Keep troubleshooting steps, verification, and outcomes clear.
- Avoid duplicating topics across files; each guide should serve a distinct practical purpose.
- Use internal company systems for actual customer, circuit, ticket, and ISP details.

## Learning Goal

Build a practical foundation in Network Operations Center (NOC) work, network monitoring, incident troubleshooting, ISP coordination, ticket management, and Root Cause Analysis as part of continued networking and cloud-security learning.
